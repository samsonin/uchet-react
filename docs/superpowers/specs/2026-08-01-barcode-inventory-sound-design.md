# Звук сканирования инвентаризации

## Цель

Восстановить звуковую обратную связь старой страницы `barcodeinventory` в новой странице `/barcode-inventory`.

## Решение

- Перенести неизменённые файлы старой версии `success.wav`, `warning.wav` и `danger.wav` в публичные ассеты React.
- Выделить воспроизведение в небольшой модуль, который создаёт новый экземпляр `Audio` для каждого события и подавляет ошибки браузерного воспроизведения.
- После ответа на сканирование воспроизводить:
  - `success.wav` при `accounted`;
  - `warning.wav` при отклонённом или повторном сканировании;
  - `danger.wav` при ошибке сети.
- Визуальное snackbar-уведомление остаётся без изменений. Невозможность воспроизвести звук не влияет на учёт позиции.

## Проверка

Модуль тестируется на выборе URL файла для каждого результата. Сценарий страницы сохраняет прежние уведомления и вызывает звуковой модуль после обработки ответа.
