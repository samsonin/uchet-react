# Группировка журнала SMS Gateway

## Цель

Не повторять текст одной SMS для каждого технического статуса её отправки.

## Представление

- Аудит-события с одинаковым `command_id` объединяются в одну карточку SMS.
- Карточка показывает текст SMS один раз, последний статус, его время и устройство.
- Карточка раскрывается: внутри перечислены предыдущие статусы этой SMS с временем каждого перехода, без повтора текста SMS.
- События без `command_id` (подключение телефона, создание кода и прочие системные действия) не объединяются.
- API уже возвращает `message` для связанных с командой событий; фронтенд запрашивает до 30 последних событий и показывает максимум пять итоговых карточек.

## Реализация и проверка

- Чистая функция группирует события в том порядке, в котором API отдаёт их (сначала новые).
- Тест проверяет объединение четырёх статусов одной команды, сохранение текста и времени последнего статуса, а также отдельную системную запись.
- `IntegrationSmsPhone` использует результат для вложенных аккордеонов журнала.
