# Единая страница инвентаризации

## Цель

Объединить обычную инвентаризацию и инвентаризацию по штрих-кодам в страницу `/inventory`.

## Интерфейс и поведение

- Первым элементом страницы располагается чекбокс «Включить сканер».
- По умолчанию чекбокс выключен и отображается существующая обычная инвентаризация.
- При включении отображается существующая инвентаризация по штрих-кодам, включая глобальный приём сканов, выбор охвата, сброс и звуковую обратную связь.
- Переключение не изменяет данные и не отправляет дополнительных запросов кроме тех, которые требуются активному режиму.

## Навигация

- Основной маршрут — `/inventory`.
- `/barcode-inventory` перенаправляется на `/inventory`, чтобы не ломать закладки и старые ссылки.
- В карте сайта остаётся единственный пункт «Инвентаризация».

## Реализация и проверка

- Новый контейнер отвечает только за состояние переключателя и выбор одного из существующих компонентов.
- `App` передаёт глобальный штрих-код контейнеру, а он передаёт его только активному режиму сканера.
- Тест контейнера подтверждает начальный обычный режим и переключение в режим сканера.
- Существующие тесты штрих-кодовой инвентаризации и production-сборка запускаются повторно.
